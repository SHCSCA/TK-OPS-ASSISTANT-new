# v1.3.4 发布记录

发布日期：2026-04-09

## 变更摘要

- 新壳启动初始化改为“宿主先拿 runtime 实际地址，再拉取 health / license / dashboard / settings”，修复默认端口被占用时前端直接报 `Failed to fetch` 的启动异常。
- `scripts/dev.ps1` 新增 runtime 端口占用探测；桌面联调模式下会自动切换到空闲端口，`-RuntimeOnly` 模式仍保持显式报错，避免静默失败。
- 全局壳层继续向旧壳密度回调：标题栏、搜索区、状态栏、侧栏底部、右侧详情区及账号/设备详情都进一步压紧，解决字体偏大与窄栏溢出问题。
- 样式基线测试补齐共享紧凑选择器守卫，防止后续共享 CSS 回退导致顶部和详情区再次膨胀。
