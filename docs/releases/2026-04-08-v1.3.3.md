# v1.3.3 发布记录

发布日期：2026-04-08

## 变更摘要

- 新壳继续按 1:1 深迁标准补齐自动化与内容域页面，当前真实新链路页面增至 `14` 个。
- 新增真实页面与数据链路：
  - `设备管理`
  - `素材中心`
  - `定时发布`
  - `数据采集助手`
  - `创意工坊`
  - `AI 内容工厂`
  - `视频编辑`
- Python runtime 新增并接通多组 HTTP 能力：`assets`、`activity`、`experiments`、`workflows`、`video-editor`。
- 新壳菜单按当前产品范围收口到 `34` 个页面，并移除不再保留的 `operations-center` 入口。
- 全局壳层密度与字号完成一轮回调，默认桌面信息密度收紧，不再整体偏大。
- 版本治理补齐到桌面前端与 Tauri 元数据：`package.json`、`tauri.conf.json`、`Cargo.toml` 现在也纳入 `build.py --sync-version-metadata` 的受管范围。
